# ETSI EN 304 627 概覽

<span class="status status-review">核准階段｜尚不得寫成已發布調和標準</span>

## 主題與適用範圍

ETSI EN 304 627 的工作項目名稱為 **Cybersecurity requirements for routers, modems intended for connection to the internet, and switches**。它聚焦路由器、預定連接 Internet 的數據機，以及交換器的產品資安要求與評估方法。

產品是否落入範圍不能只看商品名稱，仍需確認其功能、介面、部署方式與標準中的產品定義。

## 與 CRA 的關係

此工作項目是依 European Commission standardisation request M/606 推動的候選歐洲標準之一，但「正在制定候選標準」不等於「已發布為 EN」，更不等於「已在歐盟官方公報列為 CRA 調和標準」。

在法律地位未完成確認前，較準確的寫法是：

> EN 304 627 可作為網通產品資安要求與證據規劃的重要技術參考；是否能提供 CRA 的 conformity presumption，須依最終標準與歐盟官方公報引用狀態確認。

## 建議閱讀重點

- 產品情境、資產與外部介面。
- 安全能力與預設設定。
- 身分驗證、授權與敏感資料保護。
- 軟體與韌體更新。
- 漏洞處理與產品生命週期資訊。
- 評估方法、測試前置條件與證據要求。

本站不重製標準條文；正式要求、編號與測試程序應由合法取得的現行文件確認。

## 常見誤解

- **編號已經存在就代表標準已發布：**工作項目可在制定階段取得編號，仍需看官方狀態。
- **候選調和標準等於調和標準：**須完成標準程序並確認歐盟官方公報引用。
- **符合單一標準就涵蓋全部 CRA 義務：**標準範圍與法律義務需逐項對照。
