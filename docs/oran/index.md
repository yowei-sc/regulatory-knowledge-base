# O-RAN 安全規格定位

<span class="status status-spec">產業規格</span>

## 主題與適用範圍

O-RAN ALLIANCE Working Group 11（Security Working Group）負責 O-RAN 架構的安全面向。安全測試規格用於建立可重現的安全測試方法與判定依據，協助驗證元件、介面及部署控制。

它屬於產業規格，不應直接寫成歐盟法律義務。若專案同時涉及 CRA、電信法規或採購要求，應建立各來源與測試證據的對照，而不是把文件名稱互相替換。

## 來源、版本與狀態

本站以 O-RAN ALLIANCE 於 2026 年 10 月公布的技術文件清單及 Security Test Specifications v14.00 為目前版本線索，查證日期為 2026-11-16。正式使用前仍應從 O-RAN ALLIANCE 的授權取得管道確認完整文件、版本及適用條件。

## 安全測試的角色

測試規格能協助回答：

- 測試對象及前置狀態是什麼？
- 應送出哪些輸入、觸發哪些狀態？
- 觀察點、日誌與網路證據在哪裡？
- 成功、失敗與不適用如何判定？
- 測試結果可以支持到哪個範圍？

測試結果本身不自動代表產品符合所有安全要求，也不取代架構風險分析、供應鏈管理與持續漏洞處理。
